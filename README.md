# 2.5-Conditional-Access-If-Then-Security
Everything is Conditional!


"Conditional Access is the engine that decides, on every single sign-in, whether this particular attempt right now is allowed, blocked, or allowed only after jumping through an extra hoop"


Microsoft has been following the Zero-Trust policy engine. What is Zero Policy?

"Zero Trust is a cybersecurity model based on “never trust, always verify,” requiring continuous authentication and authorization for every user, device, and connection, regardless of network location."
